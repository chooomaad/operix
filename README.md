# OPERIX

Application terrain HSSE : « Report • Understand • Prevent ».

| Dossier | Rôle |
|---|---|
| [`operix-mobile/`](operix-mobile/) | Application mobile (Expo / React Native / TypeScript) |
| [`operix-supabase/`](operix-supabase/) | Backend Supabase (Postgres, Auth, Storage, Edge Function `api`) |
| [`operix-admin/`](operix-admin/) | Portail web séparé pour gérer les utilisateurs |

```bash
git clone <url-du-depot> operix
cd operix
```

configuration du portail web sont décrits dans [`operix-admin/README.md`](operix-admin/README.md).
